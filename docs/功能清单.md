# autoFtpSync功能清单

| 项    | 内容                                     |
| ---- | -------------------------------------- |
| 版本   | v1.0（草案）                               |
| 日期   | 2026-08-10                             |
| 形态   | Windows 桌面程序（Qt 5.14.2 / MinGW 32-bit） |
| 同步方向 | 单向上传（本地 → FTP 服务器）                     |
| 触发方式 | 实时监控（文件系统监听）                           |

## 1. 产品定位

一款 Windows 桌面工具：实时监控用户指定的本地文件/文件夹变化，自动将新增、修改的文件上传到 FTP 服务器，实现「本地 → 服务器」的单向自动同步。适合网站静态资源发布、程序部署、素材备份等场景。

## 2. 优先级说明

- **P0**：首个可用版本必须实现，缺失则产品不可用。
- **P1**：提升易用性与可靠性，首版之后尽快补齐。
- **P2**：锦上添花，按需排期。

### 3.8 软件版本管理

#### 3.8.1 版本号规范

采用三段式语义化版本号：**主版本.次版本.修订号**（如 `1.2.3`）。

- **主版本**：不兼容的重大架构调整、界面重构或功能模块重构时递增；
- **次版本**：新增功能（如上表新增 F 编号项）时递增；
- **修订号**：Bug 修复、性能优化、文案调整等无新增功能的改动时递增。

版本号全局唯一，统一在 `main.cpp` 的 `QCoreApplication::setApplicationVersion()` 中维护，界面标题栏、托盘提示、关于对话框、Web 管理页均读取该值展示，避免多处维护不一致。

#### 3.8.3 更新检查（规划）

- 提供"关于/检查更新"入口，手动发起版本检查；
- 从服务器版本清单文件（如 `version.json`）获取最新版本号，与本机版本比对；
- 检测到新版本时提示用户，可跳转下载页获取新版本安装包；
- 检查频率与自动下载安装不在首版范围，后续按需排期。

## 4. 后续迭代方向

- 定时同步：定时全量比对任务，作为实时监控遗漏的兜底；
- 多平台支持（macOS / Linux）。

## 5. 非目标功能

- 不支持双向同步与冲突合并；
- 不支持 FTPS / SFTP（仅 FTP）；
- 不支持服务器 → 本地的下载同步；
- 不支持文件内容级差异同步（仅整文件传输）。
