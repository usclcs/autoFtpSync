## 1. 软件简介

autoFtpSync 是一款 Windows 桌面自动同步工具。它实时监控用户指定的本地目录，一旦目录中的文件**新增或修改**，即自动将最新文件上传到 FTP 服务器，实现「本地 → 服务器」的单向自动同步，全程免人工干预。

**典型应用场景：**

- 网站静态资源发布（前端构建产物自动上线）
- 程序/脚本部署（本地改完即自动同步到服务器）
- 素材、文档备份到远程 FTP

**核心特性一览：**

| 类别 | 特性 |
| --- | --- |
| 实时监控 | 文件系统监听 + 兜底定时扫描双保险，大文件写入自动去抖合并 |
| 上传引擎 | 增量上传、服务器目录自动创建、失败自动重试、断点续传、上传限速 |
| 任务管理 | 多任务并发，支持新增/编辑/删除/启用停用/立即同步 |
| FTP 管理 | 内置 FTP 浏览器，支持在线查看文本/图片、下载/复制/移动/重命名/删除 |
| 远程管理 | 内置 Web 服务，浏览器远程查看状态、管理任务（增删改查） |
| 系统集成 | 最小化到托盘、开机自启（隐藏窗口）、日志落盘可配置保留天数 |

## 2. 运行环境与安装

**运行环境：**

- 操作系统：Windows 7 SP1 / 10 / 11（32 位或 64 位均可）
- 依赖运行库：程序目录自带 Qt 动态库（Qt5Core.dll、Qt5Gui.dll、Qt5Network.dll、Qt5Widgets.dll 等），无需单独安装

**安装方式：**

软件为绿色免安装程序，直接复制整个 `output` 目录（包含 `autoFtpSync.exe` 及配套 DLL、`config`、`log`、`sync_meta` 等子目录）到目标机器即可运行，双击 `autoFtpSync.exe` 启动。

> 提示：请保留程序目录下的 `config`、`log`、`sync_meta` 文件夹，配置、日志与同步记录均保存在程序所在目录中。

## 3. 快速上手

三步即可让软件开始自动同步：

1. **配置服务器连接**（[FTP 服务器配置](#5-ftp-服务器配置)标签页）
   填写「名称」「主机」，端口默认 21，输入用户名/密码，点击 **测试连接** 确认可达，点击 **确认** 保存到链接记录。

2. **新建同步任务**（[同步任务](#6-同步任务管理)标签页）
   点击 **新增任务**，填写任务名称、选择本地目录、服务器目录（可留空表示登录根目录）、选择服务器连接，保存。

3. **启用任务**
   任务列表中勾选「启用」状态（保存时默认启用），软件即开始监控本地目录，文件变化自动上传。

在 **日志** 标签页可实时查看上传进度与结果，状态栏显示「运行中任务 X/Y、累计上传、累计失败」。

## 5. FTP 服务器配置

### 5.1 表单字段

| 字段 | 说明 |
| --- | --- |
| 名称 * | 连接别名，唯一，任务通过名称引用该连接 |
| 主机 * | IP 地址或域名 |
| 协议 | FTP / FTPS-显式 / FTPS-隐式 |
| 端口 | 默认 21 |
| 用户名 / 密码 | 普通账号登录时填写；勾选「匿名登录」后自动置灰 |
| 路径编码 | UTF-8 / GBK，影响中文文件名与目录的解析，请按服务器实际编码选择 |
| 被动模式 | 默认勾选，兼容大多数 NAT/防火墙环境 |

### 5.2 操作按钮

| 按钮 | 功能 |
| --- | --- |
| 新增 | 清空表单进入新增模式，填写后点「确认」保存 |
| 确认 | 保存当前表单：列表有选中行时保存为对该行的修改，否则新增一条记录 |
| 删除 | 删除选中的连接（被任务引用的连接无法删除，需先删除或改绑相关任务） |
| 测试连接 | 按当前表单发起连接并列出根目录，成功/失败均给出明确提示 |
| 清空表单 | 清空表单内容 |
| 导入 | 从 JSON 文件导入服务器配置，同名连接会被覆盖 |
| 导出 | 将当前全部连接导出为 JSON 文件（密码以加密形式保存），便于多机迁移 |

### 5.3 使用说明

- 保存后连接出现在下方「链接记录」列表，选中某条记录可回填到表单进行编辑。
- 修改服务器名称后，引用旧名称的任务会自动更新引用，正在运行的任务连接也会刷新。
- 测试连接通过后，软件会自动以该连接建立真实 FTP 会话并列出根目录。

## 7. 实时监控与上传机制

### 7.1 监控方式

- **文件系统监听**：递归监听任务本地目录下所有子目录，捕获文件的创建、修改、删除、重命名。
- **兜底定时扫描**：每 5 秒对目录树做一次增量比对，与已同步元数据对照，弥补文件监听可能漏报的情况；程序启动后、任务恢复后也会自动扫描补传。

### 7.2 文件写入去抖

大文件写入期间文件系统会产生多次修改事件。软件对每个文件维护去抖机制：

- 文件事件触发后进入「待定」状态，等待在设定的**去抖时间**（默认 1500 毫秒，可在系统设置中调整）内不再有新事件；
- 静默超过该时长才判定写入稳定，将文件加入上传队列。

### 7.3 上传流程

1. 文件写入稳定后入队；
2. 连接服务器（失败自动重连，每 30 秒重试一次）；
3. 自动在服务器端逐级创建缺失的目录；
4. 执行上传，**自动断点续传**（检测到服务器已有部分内容时，从断点继续传）；
5. 上传成功后更新本地同步记录（文件大小 + 修改时间）。

### 7.4 失败重试

- 上传失败自动重试，默认最多 **3 次**，间隔按指数递增（5 秒 / 10 秒 / 20 秒）；
- 重试耗尽后文件计入失败清单，可在日志页点击「重试失败文件」手动重试。

### 7.5 上传限速

可在系统设置中设置上传限速（KB/s，0 为不限速），避免同步占满带宽。修改后对正在运行的任务立即生效。

### 7.6 忽略规则

- 精确匹配：规则与文件名完全一致（如 `.git`、`Thumbs.db`）；
- 通配符匹配：含 `*`、`?`、`[` 的规则按通配符匹配文件名或相对路径（如 `*.tmp`、`*.log`）；
- 目录忽略：规则与相对路径一致或为相对路径前缀时，该目录下文件全部忽略。

### 7.7 删除同步策略

默认关闭：本地删除文件不影响服务器，仅清理本地同步记录。开启「本地删除文件时同步删除服务器上的文件」后，本地删除已上传文件时，服务器端对应文件将被删除。

## 9. Web 远程管理服务

内置轻量 HTTP 服务（端口 **8899** 固定），可在其他设备上用浏览器远程查看同步状态、日志，并管理同步任务。

![image-20260811111047407](C:\Users\lics\AppData\Roaming\Typora\typora-user-images\image-20260811111047407.png)

### 9.1 启动服务

「Web 远程管理服务」标签页：

1. 点击 **启动服务**，状态变为「运行中（端口 8899）」；
2. 复制「访问地址」发送给需要访问的人（地址形如 `http://本机IP:8899/?token=xxx`）；
3. 如需对外开放，请确保防火墙放行 8899 端口。

### 9.2 访问令牌

- 访问地址必须携带访问令牌（`?token=xxx`），无令牌或令牌错误返回 401；
- 令牌在「访问令牌」栏显示，可点击 **重新生成** 更换（旧令牌立即失效）；
- 上次关闭软件时若 Web 服务处于开启状态，下次启动会自动恢复服务。

## 10. 系统设置

![image-20260811111135371](C:\Users\lics\AppData\Roaming\Typora\typora-user-images\image-20260811111135371.png)

### 10.1 启动设置

- **开机自启动**：勾选后，登录 Windows 时自动运行本软件（带 `--autostart` 参数，不显示主窗口，仅托盘后台运行），并自动恢复已启用的同步任务与 Web 远程管理服务。
- 实现方式为写入当前用户注册表启动项（`HKEY_CURRENT_USER\Software\Microsoft\Windows\CurrentVersion\Run`），仅对当前用户生效。

### 10.2 日志设置

- **日志保留天数**：默认 30 天。日志按天写入 `log/` 目录下的 `yyyy-MM-dd.log` 文件，修改保留天数后立即清理过期日志。

### 10.3 同步设置

| 项 | 默认值 | 说明 |
| --- | --- | --- |
| 文件去抖时间 | 1500 毫秒 | 文件写入（修改事件持续产生）需静默超过该时长才判定稳定并开始上传，范围 100~60000 毫秒；修改后对运行中任务立即生效 |
| 上传限速 | 不限速（0） | 限制上传速度避免占满带宽，范围 0~1048576 KB/s |

### 10.4 软件版本

- 显示当前版本（与窗口标题、托盘提示、Web 页面一致，全局统一维护）；
- **更新地址**：填写 `version.json` 的 URL（留空使用内置默认地址），输入完成后自动保存；
- **检查更新**：访问更新地址获取最新版本号，与本机比对后弹出提示（发现新版本显示版本号与更新说明）。

## 12. 系统托盘与开机自启

![image-20260811111204965](C:\Users\lics\AppData\Roaming\Typora\typora-user-images\image-20260811111204965.png)

### 12.1 托盘行为

- 点击主窗口关闭按钮 → 程序隐藏到系统托盘（任务栏不显示图标），**不会退出**；
- 单击/双击托盘图标 → 恢复显示主界面；
- 右键托盘图标 → 菜单：「显示主界面」「退出」。

### 12.2 托盘图标状态

| 图标 | 含义 |
| --- | --- |
| 彩色图标 | 有任务正在运行（提示文字显示「运行中（X/Y 个任务）」） |

- 在「系统设置 → 启动设置」勾选「开机自启动」；
- 自启动时程序不显示主窗口，仅托盘运行，并自动恢复已启用的同步任务与 Web 服务；
- 取消勾选即删除注册表启动项。

### 12.4 退出程序

请通过托盘菜单的「退出」彻底退出；直接关窗口只是最小化到托盘。

## 13. 配置与数据文件

所有数据保存在**程序所在目录**下：

| 路径 | 内容 |
| --- | --- |
| `config/config.json` | 全局设置、服务器连接、任务配置。密码以加密（混淆）形式存储，非明文 |
| `sync_meta/sync_meta_<任务id>.json` | 每个任务的已上传文件记录（相对路径 → 大小 + 修改时间），用于增量判断与去重 |
| `log/yyyy-MM-dd.log` | 按天滚动的运行日志（UTF-8 编码），保留天数可配置 |

**迁移建议：** 复制整个程序目录即可完成迁移，配置、任务、同步记录、日志随程序一起带走。服务器配置也可用「导出/导入」功能单独迁移。

## 14. 常见问题（FAQ）

**Q1：本地文件修改了，服务器上没更新？**
- 检查任务是否处于「监控中」状态（状态列）；
- 检查文件是否被「忽略规则」命中；
- 文件写入可能需要等待去抖时间（默认 1.5 秒）才上传；
- 查看日志页是否有上传失败记录，必要时点「重试失败文件」。

**Q2：任务一直显示「连接失败」？**
- 确认服务器地址、端口、账号密码正确（可先测试连接）；
- 确认服务器允许该 IP 访问、防火墙未拦截；
- 软件会自动每 30 秒重连，也可「启用/停用」任务强制重连。

**Q3：中文文件名上传后乱码？**
在「FTP服务器配置」中为该连接选择正确的「路径编码」（UTF-8 或 GBK），与服务器实际编码一致。

**Q4：如何让软件开机自动运行？**
「系统设置 → 启动设置」勾选「开机自启动」。自启动时软件隐藏到托盘，任务自动恢复。

**Q5：大文件上传中断了怎么办？**
无需处理。上传支持自动断点续传，下次触发时从断点继续。

**Q6：怎样在其他电脑上查看同步状态？**
在「Web 远程管理服务」页启动服务，复制访问地址，在其他设备的浏览器中打开（需能访问该端口）。

**Q7：想限制上传速度避免占带宽？**
「系统设置 → 同步设置」设置「上传限速」为指定 KB/s 数值（0 为不限速）。

**Q8：如何防止某些临时文件被上传？**
在任务编辑的「忽略规则」中按行填写规则，如 `*.tmp`、`*.log`、`.git`、`cache/`。

## 15. 使用限制与注意事项

- **单向同步**：仅支持本地 → 服务器上传，不支持服务器 → 本地下载同步，也不支持双向同步与冲突合并；
- **协议**：支持 FTP 及 FTPS（显式/隐式），不支持 SFTP；
- **传输粒度**：整文件传输，不做文件内容级差异同步；
- **密码存储**：密码以混淆加密形式保存在本地配置文件中，请妥善保管程序目录；明文密码不会写入配置文件；
- **本地目录校验**：新建任务时本地目录必须已存在，否则无法保存；
- **服务器目录**：远端目录不存在时会自动创建，无需手工建目录；
- **删除策略默认关闭**：未开启「删除同步」时，本地删除文件不会影响服务器，避免误删远端数据。
