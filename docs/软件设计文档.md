#### 1. 开源文件自动同步软件调研：

##### 1.1 FreeFileSync

- 官网：<https://freefilesync.org/> ；开源协议 GPLv3，完全免费；跨平台（Windows / macOS / Linux）
- 定位：文件夹比较与同步备份工具，先对比差异再执行同步，避免全量拷贝
- 核心功能：
  - 同步模式：镜像（Mirror）、双向（Two-way）、更新（Update）、自定义规则
  - 文件比较方式：修改时间、文件大小、二进制内容
  - 实时监控：RealTimeSync 组件，目录变化自动触发同步
  - 批处理作业、命令行支持、可复用同步配置
  - 版本控制（保留被删除/覆盖文件）、回收站支持、冲突检测与解决、同步前预览
  - 过滤规则（包含/排除）、详细日志、邮件通知、卷影复制锁定文件
  - Unicode / 长文件名 / 4GB+ 大文件、多线程优化拷贝
  - 支持本地文件夹、移动硬盘、U盘、NAS、局域网共享、FTP / SFTP 服务器
- 最新版本：14.10（2026-06）
- 与本产品对比：功能最全的成熟开源参照；但"实时监控 + 单向上传到 FTP"需依赖 RealTimeSync 组件二次配置，非开箱即用

##### 1.2 AutoFTP（同名多款，取代表开源实现）

- GitHub 开源实现（FiveAtoms/AutoFTP）：
  - 地址：<https://github.com/FiveAtoms/AutoFTP>
  - 技术栈：Python 3 命令行工具，最后更新 2019 年（停更）
  - 功能：监控本地文件夹，自动同步到 FTP 服务器，支持目录同步
  - 局限：重命名文件时旧文件残留在服务器端；仅单目录同步；无图形界面
- 同名商业/免费工具（供对比）：
  - AutoFTP Client（Auto Shutdown Pro，免费）：灵活的定时上传/下载调度、备份
  - Auto FTP Premium（PrimaSoft，共享软件 $95）：调度、同步镜像、加密/ZIP、邮件通知
  - Auto FTP Manager（DeskShare，商业 $289.95）：任务调度、多服务器并发、SFTP/FTPS、文件夹监控触发
- 与本产品对比：开源 AutoFTP 仅是最小原型；商业版功能强但闭源收费，本产品以开源免费 + 图形界面切入该场景

##### 1.3 AutoSyncFTP（同步快梭）

- 来源：PC6 等软件下载站，中文免费软件，开发商 joyinternet.net
- 定位：FTP 自动上传 / 网站同步工具，针对网站"文件数量多、体积小"的更新场景优化
- 核心功能：
  - 记录站点所有文件（含仅服务器端存在的文件）的目录结构与日期、大小，据此同步
  - 多线程与多文件并发传输，整体同步速度较常用 FTP 软件提升 200%\~500%
  - 增量传输，带日志记录；断点上/下传（结合 IE 的 HTTP/FTP 断点续传下载）
- 平台：Windows（老版本支持 Win9x/NT/2000/XP/2003）
- 状态：版本停留 v1.2，官网可能已停止维护，闭源、不跨平台、无持续更新
- 与本产品对比：功能定位与本产品最接近（FTP 实时/增量上传网站文件），但已停更；本产品可承接其使用场景并提供持续维护

##### 1.4 调研结论对比

| 维度           | FreeFileSync            | AutoFTP | AutoSyncFTP | autoFtpSync（本产品）          |
| ------------ | ----------------------- | ------- | ----------- | ------------------------- |
| 是否开源         | GPLv3 开源                | 部分开源    | 免费但闭源       | 自研（Qt 5.14.2）             |
| 跨平台          | Windows / macOS / Linux | 视具体实现   | 仅Windows    | Windows                   |
| FTP 实时单向上传   | 需 RealTimeSync 二次配置     | 基础命令行实现 | 支持          | 原生支持（文件监听自动上传）            |
| 多任务 / 多服务器   | 支持                      | 弱       | 一般          | 支持（多任务并发、多服务器管理）          |
| FTP 服务器端浏览管理 | 部分                      | 弱       | 有           | 完整（列表/分页/下载/复制/移动/删除/重命名） |
| 配置导入导出       | 支持                      | 无       | 无           | 支持（服务器配置导入/导出）            |
| 维护状态         | 持续更新                    | 停更      | 停更          | 持续开发                      |
